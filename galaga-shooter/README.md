# Galaga Shooter

A small browser game inspired by classic arcade shooters. Open `index.html` in y
our browser to play.

## Controls

- **Left / Right Arrows** – Move the ship
- **Space** – Shoot

All game logic is contained in `game.js` and the styling in `style.css`. Asset f
iles (images or sounds) can be placed in the `assets/` directory.
